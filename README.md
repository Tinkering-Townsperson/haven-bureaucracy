# haven-bureaucracy
jumpstart haven submission


The game I've made for jumpstart haven is quite simple (made it in less than an hour, I've used godot before).

## The premise:

you play as Paya (that's me!) trying to collect all the Fraser Hack Club stickers spilt on the ground.

...

yeah that's pretty much it

## controls:

| action | input options |
|--------|---------------|
| left   | `A` or left arrow key |
| right  | `D` or right arrow key |
| jump/up | `W` or `space` or up arrow key|

try it out at https://afternoonpm.itch.io/paya-fhc-collector !
